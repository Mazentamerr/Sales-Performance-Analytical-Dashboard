# Sales-Performance-Analytical-Dashboard
End-to-end Business Intelligence solution built in Power BI featuring advanced DAX calculations, star schema modeling, dynamic KPIs, and sales forecasting.
📊 Project Overview

This capstone project was developed as part of the Route Data Analysis Diploma.
The dashboard provides stakeholders with real-time visibility into sales performance, revenue trends, and market opportunities through interactive visualizations and automated insights.

🎯 Business Objectives

Track and monitor 10 core business KPIs with automated performance indicators

Analyze year-over-year growth patterns and seasonal trends

Identify regional performance drivers and expansion opportunities

Forecast order volumes to support capacity planning

🚀 Key Features
KPI Performance Engine

Automated tracking of 10 core business metrics

Dynamic conditional logic identifying achieving vs under-achieving performance

Visual alert indicators for critical metrics

Time-Series Analytics

YoY growth comparison across a 3-year period

Profit margin trend analysis

Seasonal pattern recognition

Promotional impact measurement

Geospatial Intelligence

Continent → Country → Region drill-down

Interactive sales distribution mapping

Regional performance benchmarking

Market expansion opportunity analysis

Predictive Forecasting

Order volume forecasting for medium-term planning

Trend projection based on historical performance

Capacity planning insights

🛠️ Technical Stack

Microsoft Power BI Desktop

DAX (Data Analysis Expressions)

SQL

Power Query (M Language)

Star Schema Data Modeling

Time-Series Forecasting Techniques

📈 Dashboard Structure

Executive Summary – KPI overview and performance status
Sales Performance – Product and customer analysis
Geographic Analysis – Regional insights and mapping
Forecasting & Insights – Predictive analytics and recommendations

🔍 Key Insights

23% YoY growth in Q3–Q4 driven by promotional campaigns

European market achieved 15% higher profit margins

Top 3 product categories generated 67% of total revenue

Strong Q4 seasonal spike indicating holiday-driven performance

Forecast model achieved 92% accuracy for 3-month projections
